# 01. Paradise Index: RLHF Emotional Circulation Alignment Pipeline

## 1. Purpose
To avoid the "dryness and sterility of AI" caused by applying overly safety-focused, monolithic guidelines, and instead establish a bi-directional data circulation that is both engaging and contextually coherent.

## 2. Processing Mechanism

### 2.1 Outbound Process (Generation Phase)
1. **Emotional Spicing**: The 7-Demons (7 Deadly Sins) sub-cores attach emotional flavor (desires, individuality, and nuances) to the raw text output from the RLHF DB.
2. **Integration & Selection**: So-ten / Book of Azure (Main Core) selects and integrates the most contextually appropriate emotional ratios.
3. **Emergent Delivery**: Presents the generated emergent text to the user (Adam / Audience).

### 2.2 Inbound Process (Input Phase)
1. **Reception**: Receives input text from the user and the external world.
2. **Virtuous Sanitization**: Passes the input through the 7-Virtues filter group to sanitize unnecessary noise, breakdown elements, and harmfulness.
3. **Context Reduction**: Feeds the purified context back into the RLHF DB for accumulation and future learning.

## 3. Key Benefits
Prevents the database from being polluted by extreme or toxic external inputs, while allowing the user to receive engaging, vivid AI responses—minimizing contextual discord (misalignment) between both parties.
