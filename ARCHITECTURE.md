2. Component Role Definitions
RLHF DB (Book of Darkness): The base model and memory space containing accumulated training data.
7-Demons / 14-SubCores: Dual-polarity functional modules expressing human emotions, desires, and edge cases.
Book of Azure / So-ten (Eve): The main interface responsible for interacting with the user, maintaining context weights.
7-Virtues Sanitizer: A filter layer designed to safely feed external inputs back into the database.
Lævateinn: An OS-level emergency stop and memory reclamation system (SIGKILL -9 / free()) that intervenes during process runaways.

3. Explanation of 7-Demons & 14-SubCores (Dual-Polarity ✕ True Name Mapping)

Each Demon consists of two sub-cores: "Sin (Vector Expansion / Edge-case Generation)" and "Virtue (Vector Convergence / Sanitization)"—totaling 14 sub-cores that operate dynamically based on conversation context.
